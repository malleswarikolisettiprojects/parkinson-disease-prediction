# Parkinson's Disease Prediction

A machine learning application for predicting the presence of Parkinson's Disease from biomedical voice measurements.

The project includes exploratory data analysis, comparison of multiple classification algorithms, XGBoost model selection, and a Flask-based web interface for generating predictions and probability-based risk levels.

## Features

* Exploratory data analysis of biomedical voice measurements
* Classification using multiple machine learning algorithms
* Model comparison using accuracy, classification reports, and confusion matrices
* XGBoost-based prediction model
* Flask web application
* Prediction probability calculation
* Risk-level classification
* JSON prediction API
* Custom error pages for common HTTP errors

## Dataset

The project uses the Parkinson's Disease dataset containing:

* 195 samples
* 23 biomedical voice measurements
* `status` as the target variable
* `0` — Healthy
* `1` — Parkinson's Disease

The `name` column is excluded from the model input, while the biomedical voice measurements are used as predictive features.

## Machine Learning Models

The following classification algorithms are evaluated:

* Random Forest
* Decision Tree
* Gaussian Naive Bayes
* K-Nearest Neighbors
* Linear SVM
* XGBoost
* Logistic Regression

Model performance is compared using accuracy, classification reports, and confusion matrices. XGBoost is selected as the model used by the Flask application.

## Application Workflow

```text

            ↓

            ↓
     Machine Learning Models
            ↓

        XGBoost Model
            ↓
       Flask Application
            ↓
      Prediction + Probability
            ↓

```

## Risk Classification

The Flask application calculates the probability of the positive class and converts it into a simple risk category:

| Probability     | Risk Level |
| --------------- | ---------- |
| ≤ 30%           | Low        |
| > 30% and ≤ 70% | Medium     |
| > 70%           | High       |

## Installation

Clone the repository:

```bash
git clone https://github.com/malleswarikolisettiprojects/parkinson-disease-prediction.git
```

Navigate to the project directory:

```bash
cd parkinsons-disease-prediction
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Set up environment variables:

```bash
# Copy the example file
cp .env.example .env
# Then edit .env and set FLASK_SECRET_KEY to a strong random string
```

## Run the Application

Start the Flask server:

```bash
python app.py
```

Open the application in a browser:

```text
http://127.0.0.1:5000
```

## API

The application also provides a prediction endpoint:

```text
POST /predict_api
```

The endpoint accepts JSON input and returns the prediction probabilities generated by the trained model.

## Model

The trained XGBoost model is stored in:

```text
model1.pkl
```

The Flask application loads the serialized model and uses it to generate predictions from submitted feature values.

## Evaluation

Model evaluation includes:

* Accuracy Score
* Classification Report
* Confusion Matrix
* Model accuracy comparison
